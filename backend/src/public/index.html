RTMP Web Player

A self-hosted live streaming platform for broadcasting live services and events on the web.

What this is

RTMP Web Player lets an organisation broadcast a live video stream directly on its own website, without depending on a third-party streaming service. A broadcaster sends video from their streaming software to this platform, which then makes it available to viewers through an embedded web player.

What it does

  • Live web playback - an embeddable player that can be placed on any website, so visitors can watch without leaving the site or needing an account.
  • Optional relay to YouTube - an administrator can choose to simultaneously publish the same live stream to their own YouTube channel.
  • Recording - an administrator can optionally record a stream for later private playback.
  • Basic viewer analytics - anonymised, aggregate information about how many people watched, for the organisation's own internal use.

Why we ask for YouTube access

When an administrator chooses to connect their YouTube channel, this app requests access to their YouTube account solely to create and manage a live broadcast on their behalf, so the same live stream can be published to their channel at the same time it plays here. It does not access, view, or modify anything else in their Google Account, and this access can be revoked at any time from the administrator's own Google Account settings.

Who runs this

This platform is administered privately by the organisation that operates this website. Access to the management dashboard is restricted to that organisation's own administrators.
